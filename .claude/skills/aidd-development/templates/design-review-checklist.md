# UIデザインレビューチェックリスト

## アクセシビリティ
- [ ] コントラスト比は十分か（WCAG AA: 4.5:1以上）
- [ ] フォーカス状態が視認できるか
- [ ] alt属性が適切に設定されているか
- [ ] キーボードだけで操作できるか
- [ ] スクリーンリーダーで意味が通じるか
- [ ] 色だけに依存した情報伝達がないか

## レスポンシブ
- [ ] モバイル（320px〜）で崩れないか
- [ ] タブレット（768px〜）で適切に表示されるか
- [ ] デスクトップ（1024px〜）で余白が適切か
- [ ] 文字サイズは各画面で読みやすいか
- [ ] タッチターゲットは十分な大きさか（44x44px以上）

## 一貫性
- [ ] 色はデザイントークンに従っているか
- [ ] スペーシングは統一されているか
- [ ] フォントは統一されているか
- [ ] インタラクションパターンは統一されているか
- [ ] アイコンスタイルは統一されているか

## ユーザビリティ
- [ ] CTAボタンは目立つか
- [ ] エラー状態は明確か
- [ ] ローディング状態があるか
- [ ] 空状態（データなし）のデザインがあるか
- [ ] 成功/完了のフィードバックがあるか
- [ ] 戻る/キャンセルの導線があるか

## パフォーマンス
- [ ] 画像は最適化されているか
- [ ] 不要なアニメーションがないか
- [ ] 初期表示に必要最小限のデータのみロードしているか
- [ ] レイアウトシフト（CLS）が発生しないか

## AI slop 回避
- [ ] 過度なグラデーションがないか
- [ ] 無意味なアニメーションがないか
- [ ] 一貫性のないスタイルがないか
- [ ] 情報過多な画面がないか
- [ ] 適切な余白で情報が整理されているか
