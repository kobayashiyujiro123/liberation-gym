# Theme Factory

A curated collection of professional font and color themes. Once a theme is chosen, it can be applied to any artifact.

## Purpose

Apply consistent, professional styling to presentation slide decks and other artifacts. Each theme includes:
- A cohesive color palette with hex codes
- Complementary font pairings for headers and body text
- A distinct visual identity suitable for different contexts and audiences

## Usage Instructions

1. **Present available themes** to the user
2. **Ask for their choice**
3. **Wait for selection** - get explicit confirmation
4. **Apply the theme** - colors and fonts to the artifact

## Application Process

1. Read the theme specifications
2. Apply colors and fonts consistently throughout the artifact
3. Ensure proper contrast and readability
4. Maintain the theme's visual identity across all pages/slides

## Create Your Own Theme

For cases where none of the existing themes work:
1. Accept a brief description from the user
2. Generate appropriate colors/fonts based on the description
3. Name the theme describing what the combinations represent
4. Show for review and verification
5. Apply the theme
